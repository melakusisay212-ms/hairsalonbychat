# Build the Android APK with GitHub Actions

This project is designed so the Android build happens on GitHub, not on the local PC. This is useful on low-resource machines.

## GitHub build

1. Create a GitHub repository.
2. Upload the contents of this project to the repository root.
3. Push the `main` branch.
4. Open **Actions** in GitHub.
5. Select **Build Android APK**.
6. Wait for the workflow to finish.
7. Open the completed workflow run and download the **salon-manager-debug-apk** artifact.
8. Extract the artifact ZIP and install `app-debug.apk` on Android.

The workflow installs Node.js 20 and Java 17, builds the Vite/React app, creates the Capacitor Android project, installs the local SalonSms native plugin, syncs Capacitor, and runs Gradle `assembleDebug`.

## Important

- Do not commit `node_modules/`, `dist/`, or generated Android build output.
- The `android/` directory is generated by the workflow and is intentionally not required in the repository.
- The local native plugin source at `plugins/salon-sms/android/src/main/java/com/melakusisay/salonsms/SalonSmsPlugin.java` must remain in the repository.
- The debug APK is unsigned for Play Store release. For Play Store distribution, create a separate signed release workflow later.

## Local build

A full Android build is not recommended on a 2 GB RAM / 32 GB storage PC. Use GitHub Actions instead.
